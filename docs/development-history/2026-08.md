## commit-7268f3ef91a2296c32bc550bc987f32711363061

**변경 날짜:** 2026-08-13T02:55:44+09:00

**원본 변경 제목:** feat(chat-history): title from first Q+A exchange at run completion (was: first message at send)

**변경 설명**

amicus 첫 메시지를 보내는 순간의 내용으로 제목을 정하던 흐름을 바꿔, 첫 질문과 답변이 완료된 시점에 대화 제목을 생성하도록 했다. 제목 갱신 이벤트를 저장소와 사이드바에 전달하는 경로를 연결해 실행 완료 후의 대화 내용을 제목에 반영하도록 개선했다.

Amicus 대화가 끝난 시점의 첫 질문과 답변을 기준으로 세션 제목을 생성하고 제목 변경을 사이드바에 전달하도록 했다. Stop 이후 관찰자가 사라졌는데도 남아 있던 폴링과 실행 상태 경합을 정리해 종료 상태를 후속 화면에서도 일관되게 다루도록 개선했다.

**원본 변경 범위:** 8개 파일, 텍스트 추가 305줄 / 삭제 78줄. 생성 파일·문서·잠금 파일이 포함될 수 있습니다.

## commit-4ee2621ad666576287c522ccb6d288d805da3c84

**변경 날짜:** 2026-08-26T11:00:16+09:00

**원본 변경 제목:** feat(db): better-sqlite3 → node:sqlite 전환 (Phase B)

**변경 설명**

amicus 데이터베이스 드라이버를 better-sqlite3에서 node:sqlite로 전환하는 변경을 반영했다. 같은 기간 Watcher의 후보 항목 조회와 터미널 준비 및 실행 경로를 정비해 반복 초기화와 불필요한 조회가 발생하는 지점을 줄이는 방향으로 구현했다.

Amicus 데이터베이스 드라이버를 node:sqlite로 전환하고 Watcher 중복 판정에서 전체 이력을 읽는 대신 후보 항목을 청크로 조회하도록 변경했다. 터미널 셸을 미리 준비하고 로그인 셸 환경을 재사용하는 경로를 정비해 반복 초기화와 불필요한 조회 작업을 줄였다.

**원본 변경 범위:** 16개 파일, 텍스트 추가 164줄 / 삭제 103줄. 생성 파일·문서·잠금 파일이 포함될 수 있습니다.
